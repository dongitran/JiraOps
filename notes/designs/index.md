# JiraOps Logo and Icon Design Concepts

These SVG concepts are quick vector explorations for the JiraOps extension. Each
file uses a 256x256 viewBox, no raster data, no remote assets, and an internal
title/description for review.

## Concepts

01. `jiraops-logo-01-ticket-orbit.svg` - Ticket core with orbiting ops signal; emphasizes Jira ticket focus with automation around it.
02. `jiraops-logo-02-board-pulse.svg` - Compact board columns with an active pulse; communicates triage and live updates.
03. `jiraops-logo-03-merge-compass.svg` - Merge request lanes forming a compass; positions JiraOps as navigation for issue context.
04. `jiraops-logo-04-notification-pin.svg` - Notification pin over ticket layers; focuses on assigned issue alerts.
05. `jiraops-logo-05-command-tile.svg` - Command center tile with status chips; suitable for a VS Code activity icon.
